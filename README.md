# AudioCutter 音频波形裁切工具

对一条长音频（如有声书、故事录音）人工分段打轴，然后一键导出为多个按编号命名的 MP3 文件。典型用途：把整集故事音频切成一条条「点读贴」音频，每段对应一个贴纸编号。

**两种使用方式**（功能完全一致）：

- **Windows 免安装 exe**：下载即用，无需装 Python（推荐）
- **Python 直接运行**：适合想改代码或非 Windows 用户

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| **波形打轴** | 加载音频后显示波形，用 Tab 键 / 工具栏按钮 / 右键菜单在任意位置标记段落边界，橙色虚线可直接拖动微调 |
| **右键菜单**（全中文） | 波形空白处右键加边界；边界线上右键删除（两侧段自动合并）；候选线上右键「转为边界 / 移除」 |
| **片段列表** | 右侧实时列出所有片段：编号自动重排、时间区间、对应文本；勾选/取消决定是否导出；顶部显示「已选 X / 共 N 段」；选中段按 Del 删除其右侧边界；双击试听该段 |
| **自动标记候选**（实验性） | 用 Silero VAD 语音检测找出最可能是段落边界的停顿位置，画成黄色虚线候选（数量 5–50 可调，默认 15）。候选仅供参考，需逐个人工确认转正。VAD 失效的音频自动降级为能量检测兜底 |
| **故事文本同步** | 加载 `---` 分隔的故事文本后，播放到哪一段，文本面板自动高亮对应段落，边听边核对 |
| **导出** | 按起始编号（默认 00201）依次导出 MP3，并生成「对应表.md」记录每段编号、时间区间、文本 |
| **撤销** | Ctrl+Z 或按钮，覆盖加/删边界、拖动、勾选排除等操作，最多 100 步 |
| **项目保存/加载** | 存成 JSON（音频路径、文本路径、边界、排除状态、编号起点），下次打开继续干 |

### 导出规则

- 文件名 = 5 位编号，从「起始编号」开始连续递增（如 00201.mp3、00202.mp3…）；
- 列表里**取消勾选**的段不导出，且**不占编号**——后面的段编号自动前移；
- 导出同时在该目录生成「对应表.md」，格式：

  | 贴纸编号 | 状态 | 时间区间 | 文本 |
  |---|---|---|---|

- 导出在后台线程执行，界面不卡；可随时取消。

### 典型工作流

1. 「打开音频」加载本集录音 → 若换新音频，上集的边界/候选/撤销记录自动清空；
2. 「加载文本」载入 `---` 分隔的故事文本；
3. 边听边按 Tab 打边界（或先点「自动标记候选」再逐个确认）；
4. 拖动橙色线微调，列表里核对每段文本；
5. 设置「起始编号」→「导出 MP3 和对应表」，完成。

## 二、Windows 使用（exe）

### 准备两样东西

1. **audio_cutter.exe**：从 [Releases](../../releases) 下载最新版（v6.3.x）；
2. **ffmpeg**：**本工具不附带，需自备**——去 [ffmpeg 官网](https://ffmpeg.org/download.html) 或 `winget install ffmpeg` 安装，并确保命令行里能直接运行 `ffmpeg`（即已加入 PATH）。

### 运行

双击 `audio_cutter.exe` 即可。解码、切分、VAD 全都通过调用 ffmpeg 完成，所以 ffmpeg 必须先装好。

### 常见问题

| 现象 | 原因与解决 |
|---|---|
| 提示找不到 ffmpeg / 解码失败 | ffmpeg 未安装或未加入 PATH，重装并确认命令行可用 |
| 打开音频后无法播放 | 播放走系统解码器，与 ffmpeg 无关；换 mp3/wav 格式试试 |
| VAD 候选报错 | silero 模型已打包在 exe 内；若仍失败会自动降级能量兜底，功能不受影响 |

> 历史版本说明：v6.3.0–v6.3.2 的 exe 存在依赖/文件缺失问题，v6.3.3 在 Windows 中文用户名下 VAD 会报错，请一律使用 **v6.3.4 及以上**版本。

## 三、从源码运行

```bash
# 基础功能（打轴+导出）
pip install PySide6 numpy pyqtgraph
# 系统需安装 ffmpeg 并加入 PATH

# 「自动标记候选」功能另需
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install silero-vad

# 运行（音频、文本都是可选参数）
python audio_cutter.py [音频文件] [故事文本.md]
```

依赖说明：

| 包 | 用途 |
|---|---|
| PySide6 | 界面 + 音频播放 |
| numpy / pyqtgraph | 波形绘制 |
| ffmpeg（系统） | 解码、切分、导出 MP3 |
| torch + silero-vad | 自动标记候选（可选，没有则该按钮报错但其他功能正常） |

## 四、项目文件格式

「保存项目」生成的 JSON：

```json
{
 "audio": "D:/audio/第1集.mp3",
 "text_file": "D:/text/第1集.md",
 "boundaries": [12.3, 45.6, ...],
 "start_id": "00201",
 "excluded": [2, 5]
}
```

注意：音频/文本存的是**本机路径**，换电脑打开项目需保证路径一致（或重新加载后路径仍有效）。

---

## 五、故事文本格式

用 `---` 空行分隔段落，每段对应一条点读贴音频：

```markdown
小兔子打开门，看见了一只大灰狼。

---

大灰狼说：小兔子乖乖，把门儿开开！

---

小兔子说：不开不开就不开！
```

若整个文件没有 `---`，则按空行分段；两样都没有就当作一整段。

## 六、打包发布（开发者）

1. **本地验证后再发版**——PyInstaller 收集失败构建时不报错，运行时才炸：

   ```bash
   pyinstaller --onefile --windowed --name audio_cutter \
     --hidden-import torch \
     --collect-all silero_vad \
     --collect-data silero_vad \
     --collect-binaries silero_vad \
     --collect-all PySide6.QtMultimedia \
     audio_cutter.py
   ```

2. 推送 `v*` 标签（或在 Actions 页手动触发）→ GitHub Actions 自动打 Windows exe 并发布 Release；
3. 详细的踩坑记录与排查流程见 [`docs/ci-packaging-lessons.md`](docs/ci-packaging-lessons.md)。
